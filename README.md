# TATTOO STUDIO | ПРЕМИАЛЬНЫЙ СЕРВИС ЗАПИСИ

Полнофункциональное веб-приложение для тату-мастера, объединяющее портфолио, витрину эскизов и автоматизированную систему бронирования.

## 🚀 Основные возможности

- **Динамический контент**: Портфолио и эскизы управляются через облачную базу данных.
- **Интеграция с Telegram**: Мгновенные уведомления мастеру о каждой новой заявке.
- **Панель администратора**: Вход по паролю, управление статусами заявок и загрузка новых работ в галерею.
- **Умный Календарь**: Система блокировки выходных дней и праздников.
- **Локализация**: Полная поддержка валюты тенге (₸) и часового пояса Астаны (GMT+5).

## 🛠 Технологический стек

- **Frontend**: React 18, Vite, Framer Motion, Lucide React, react-router-dom.
- **Backend**: Supabase (Postgres, Auth, Storage).
- **Notification**: Telegram Bot API.

## ⚙️ Настройка окружения

Для работы проекта необходимо создать файл `.env.local` в корневой директории со следующими ключами:

```env
# Supabase
VITE_SUPABASE_URL=ваш_url
VITE_SUPABASE_ANON_KEY=ваш_ключ

# Telegram
VITE_TELEGRAM_BOT_TOKEN=токен_ат_BotFather
VITE_TELEGRAM_CHAT_ID=ваш_id_от_userinfobot
```

## 🏗 Развертывание в базе данных

Все необходимые SQL-скрипты для создания таблиц и настройки политик безопасности (RLS) находятся в файле `supabase_schema.sql`.
