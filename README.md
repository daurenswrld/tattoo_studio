# TATTOO STUDIO — Премиальный веб-сервис для тату-мастера

![Hero Section](https://raw.githubusercontent.com/daurenswrld/tattoo_studio/main/public/assets/hero-bg.png)

Современный, быстрый и визуально совершенный одностраничный сервис, разработанный для автоматизации записи и демонстрации портфолио тату-мастера. Сайт спроектирован с упором на премиальную эстетику (High-End UI) и удобство пользователя.

## 🚀 Основные возможности

- **Интерактивное Портфолио**: Динамический слайдер с полноэкранным лайтбоксом для детального изучения работ.
- **Витрина эскизов**: Система фильтрации эскизов по статусам («Свободен» / «Забронирован») с плавными анимациями.
- **Система онлайн-записи**: Кастомный календарь с логикой выбора даты и времени, исключающий запись на прошедшие дни.
- **Премиальный UI**: Строгая 8-пиксельная сетка, темная тема и продуманные микро-анимации на базе `framer-motion`.
- **Полная Адаптивность**: Сайт идеально отображается как на 4K мониторах, так и на мобильных устройствах.

## 🛠 Технологический стек

- **Core**: React 18
- **Bundler**: Vite
- **Styling**: Vanilla CSS (Custom Design System)
- **Icons**: Lucide React
- **Animations**: Framer Motion

## 📦 Быстрый старт

1. **Клонируйте репозиторий**:
   ```bash
   git clone https://github.com/daurenswrld/tattoo_studio.git
   ```

2. **Перейдите в папку проекта**:
   ```bash
   cd tattoo_studio
   ```

3. **Установите зависимости**:
   ```bash
   npm install
   ```

4. **Запустите сервер для разработки**:
   ```bash
   npm run dev
   ```

## 📐 Дизайн-система

Проект использует кастомную систему стилей, основанную на переменных CSS. Все отступы, шрифты и цвета централизованы в `/src/styles/design-system.css`, что позволяет легко масштабировать проект.

- **Шрифты**: Syne (Заголовки), Inter (Основной текст).
- **Сетка**: 8px базовый шаг.

## 📞 Контакты

Разработано как премиальное решение для мастеров татуировки.
